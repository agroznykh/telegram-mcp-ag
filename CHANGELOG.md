# Список изменений

Что умеет сервер и в какой версии это появилось. Только факты, без деталей —
подробности в `TECHNICAL.md` и в истории коммитов. При каждом релизе добавляйте
сюда запись сверху.

## Что умеет сейчас

- Читает чаты Telegram: список чатов, история, поиск, контакты, участники
  (инструменты апстрима `chigwell/telegram-mcp`, режим `read-only`).
- Расшифровывает голосовые сообщения, видео-кружки, аудиофайлы и подкасты
  через нативный API Telegram. Не расшифровывает обычные видео и документы.
- Проверяет доступ к расшифровке до запроса: Premium или остаток недельной квоты.
- Читает кнопки под сообщениями бота: обычные inline-клавиатуры и кнопки
  rich-сообщений, в том числе обе сразу в одном сообщении. Сообщает текст,
  тип, признак callback и стиль кнопки (стиль отдаётся как есть).
- Нажимает callback-кнопки (в режиме не `read-only`; в `read-only` нажатие недоступно).
- Входит в Telegram по QR прямо в чате, если сессии ещё нет.
- Подсказывает команду перелогина, если сессия отозвана.
- Работает в Claude Code, Claude Desktop (Chat и Cowork), Codex CLI, ChatGPT Desktop (Work).
  В ChatGPT Desktop режим Chat инструменты не получает.
- Ставится одной командой на macOS, Linux и Windows.

## 0.3.5 — 2026-10-30

- К релизам больше не прикладывается файл `.whl`. Сервер не изменился.

## 0.3.4 — 2026-10-30

- Работает на Python 3.14. Вход по QR больше не падает на этой версии.
- Установщик ставит через `uv` и использует свой Python 3.14: системный Python
  не важен, а чужие обновления и удаления сервер не затрагивают.
- Если `TELEGRAM_EXPOSED_TOOLS` не задан, сервер работает в режиме `read-only`
  и дописывает эту строку в `config.env`.
- Для установки больше не нужен Git.

## 0.3.3 — 2026-10-23

- У кнопок обычных inline-клавиатур в списке появились `style` и `kind: disabled`
  (раньше стиль терялся, а неактивная кнопка выглядела как `other`).

## 0.3.2 — 2026-10-23

- Кнопки rich-сообщений (Bot API 10.1+): `list_inline_buttons` их видит,
  `press_inline_button` нажимает.
- Inline-клавиатуры нового формата Telegram (слой 229) читаются корректно.
- Rich-кнопки и inline-клавиатура одного сообщения идут в общем списке
  со сквозными индексами.
- В списке кнопок появились `kind` (callback, url, disabled…) и `style`.
- Кнопки с запросом облачного пароля, `disabled` и не-callback не нажимаются —
  возвращается понятный отказ.
- Если Telegram прислал сокращённую версию rich-сообщения, запрашивается полная.

## 0.3.1 — 2026-10-20
