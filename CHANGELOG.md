# Список изменений

Что умеет сервер и в какой версии это появилось. Только факты, без деталей —
подробности в `TECHNICAL.md` и в истории коммитов. При каждом релизе добавляйте
сюда запись сверху.

## Что умеет сейчас

- Читает чаты Telegram: список чатов, история, поиск, контакты, участники
  (инструменты апстрима `chigwell/telegram-mcp`, режим `read-only`).
- Расшифровывает голосовые сообщения, видео-кружки, аудиофайлы и подкасты
  через нативный API Telegram. Не расшифровывает обычные видео и документы.
- Проверяет доступ к расшифровке до запроса: Premium или остаток недельной квоты.
- Скачивает медиафайлы (голосовые, кружки, видео, фото, документы, медиа rich-постов),
  если включён режим `read-only+download_media`; по умолчанию выключено.
- Читает кнопки под сообщениями бота: inline-клавиатуры, обычную клавиатуру бота
  (вместо поля ввода), кнопки rich-сообщений и кнопки внутри их текста (клетки
  доски, таблицы) — в одной нумерации, со строкой и столбцом. Сообщает текст,
  тип кнопки, её данные по типу (ссылка, текст для копирования…) и стиль как есть.
- Нажимает callback- и game-кнопки (в режиме не `read-only`; в `read-only` нажатие
  недоступно). Кнопки, которые отправили бы текст, телефон или геолокацию, не нажимает
  и объясняет почему.
- Сообщает свою версию клиенту при подключении; установщик показывает версию.
- Входит в Telegram по QR прямо в чате, если сессии ещё нет. QR открывается
  в браузере и сам обновляется, пока его не отсканируют.
- Замечает отозванную сессию и при запуске, и при вызове инструмента: удаляет
  её и предлагает вход в чате; подсказывает команду перелогина.
- Установщик входит в Telegram без лишних вопросов: по QR, а если не вышло —
  по номеру телефона. При повторном входе не спрашивает api_id и api_hash заново.
- Работает в Claude Code, Claude Desktop (Chat и Cowork), Codex CLI, ChatGPT Desktop (Work).
  В ChatGPT Desktop режим Chat инструменты не получает.
- Ставится одной командой на macOS, Linux и Windows.

## 0.5.2 — 2026-11-09

- Установщик для Windows находит Claude Desktop из Microsoft Store: данные у него
  лежат в `%LOCALAPPDATA%\Claude-Data\claude_*`, а не в `%APPDATA%\Claude`. Если
  приложение установлено, но ни разу не запускалось, установщик говорит об этом, а не
  молчит. Конфиг создаётся, если папка есть, а файла ещё нет.
- Установщик находит Claude Code, встроенный в Claude Desktop (его нет в `PATH`),
  регистрирует в нём сервер и ставит скилл `telegram-digest`.
- Установщики (Windows, macOS/Linux) в конце говорят, что делать с каждым клиентом:
  Claude Desktop закрыть полностью (на Windows — значок в области уведомлений →
  «Выход», запасной путь — перезагрузка; на Mac — `Cmd+Q`), в Claude Code и Codex
  открыть новую сессию, ChatGPT Desktop перезапускать не нужно.
- Подсказки установщиков о повторном входе и удалении дают полную команду для вставки
  в терминал, а не `install.ps1`/`install.sh`, которых у человека в папке нет.
- Команда запуска установщика на Windows идёт с `-ExecutionPolicy Bypass`: без него
  PowerShell на части машин отказывается запускать скачанный скрипт.

## 0.5.0 — 2026-11-05

- Апстрим `chigwell/telegram-mcp` обновлён до v3.3.4: медиа из rich-постов,
  кириллица и эмодзи в ответах читаемым текстом, `get_pinned_messages` отдаёт все
  закреплённые, у `search_global` есть `next_cursor`, админы и баны в обычных группах,
  исправления под Windows. Новый изменяющий инструмент `set_default_send_as` в
  `read-only` скрыт.
- Подсказка о перелогине работает и в инструментах пользовательских эмодзи.
- Скачивание медиа — опция: режим `read-only+download_media`. Файлы ложатся в папку
  `Telegram` проекта, а если клиент папку не сообщает — в `Загрузки/Telegram`.
- `download_media` принимает `media_id` строкой: длинный id медиа rich-поста
  Claude Code и Claude Desktop больше не округляют.
- Кнопки: строка и столбец у каждой кнопки, обычная клавиатура бота (`keyboard: reply`),
  `kind` по типу кнопки и поля по типу (`url`, `copy_text`, `query`, `user_id`…),
  кнопки внутри текста rich-сообщения (клетки доски, таблицы).
- Нажатие: game-кнопки нажимаются; ссылки и копирование возвращают ссылку или текст;
  кнопки reply-клавиатуры, запросы телефона и геолокации не нажимаются, с объяснением.
  Ответ бота — с `alert` и `url`; таймаут бота и устаревшая клавиатура — понятным текстом.
- Нажатие по подписи не зависит от невидимых символов в ней (неразрывный пробел,
  селектор эмодзи). Если подпись у нескольких кнопок, сервер просит индекс, а не
  нажимает первую; подпись, не совпавшая с индексом, — отказ.
- Сервер сообщает клиенту свою версию (`serverInfo.version`), установщики показывают
  версию в строках «Устанавливаю…» и «…установлен».

## 0.4.0 — 2026-11-03

- Свой вход в терминале вместо генератора сессии апстрима: QR-код, запасной
  вход по номеру телефона, без вопросов про label и `.env`. Строка сессии на
  экран не выводится, сразу записывается в `config.env`.
- При повторном входе `api_id` и `api_hash` берутся из `config.env`; спрашиваются,
  только если их нет или Telegram их не принял.
- Новый вход заменяет прежние сессии в `config.env`.
- Установщик больше не спрашивает про автоподтверждение: инструменты чтения
  разрешаются всегда.
- Сервер при запуске проверяет сессию: если Telegram её отозвал, удаляет её и
  стартует в режиме входа в чате (раньше клиент не мог запустить сервер).
- `AUTH_KEY_DUPLICATED` (одна сессия на двух компьютерах) распознаётся как
  отозванная сессия.
- Вход в чате: QR открывается в браузере страницей, которая сама показывает
  свежий код; картинки QR в чате больше нет. Сообщение о неверных `api_id`/`api_hash`
  содержит команду перелогина.
- Тексты для пользователя и ассистента не называют, где лежат секреты.
- Скилл `telegram-digest` 1.2: показывать команду перелогина при неверных ключах,
  никогда не просить содержимое `config.env`. Архив скилла лежит в репозитории
  с версией в имени и скачивается сразу в Загрузки.
